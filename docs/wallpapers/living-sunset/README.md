# 夕日 / Living Sunset

草原、都市、海岸、山岳の夕景を WebGL2 で描画します。WebGL2 が使えない場合は Canvas 2D で簡易表示します。

- 景色とシードを選ぶと、同じ地形、雲の量、太陽と空の色をURLで共有できます。
- 太陽の進行と再生速度を調整できます。PNG画像と設定JSONの保存にも対応しています。
- 「設定を閉じる」で景色だけを表示し、「設定を開く」で操作に戻れます。H または Esc で設定を切り替え、F で全画面表示にします。全画面の対応状況はブラウザに依存します。

Claude Fable 5.2 が生成した実装をもとにしています。大気や反射は視覚表現のための近似です。外部の画像、動画、ライブラリは使用していません。
