# 焚き火 / Campfire

薪の燃焼、炎、熾火、煙、火の粉をブラウザで描画します。炎は WebGL2 で描画し、利用できない環境では Canvas 2D に切り替えます。

- 薪をくべたり、炎をあおったりできます。左右にドラッグすると風向きが変わります。
- 薪の自動補充と風の設定はブラウザに保存されます。
- 環境音は初期状態では消音です。「音」を押すとブラウザで合成した音が流れます。
- 操作パネルは一定時間で隠れ、画面に触れるか、ポインターを動かすと表示されます。

Claude Fable 5.2 が生成した実装をもとにしています。外部の画像、音声、ライブラリは使用していません。
