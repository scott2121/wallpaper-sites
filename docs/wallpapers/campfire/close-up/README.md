# 薪一本の寄り画

一本の薪が燃え、赤い熾火になり、灰が崩れて下に残る様子を固定カメラの構図で描きます。再生、一時停止、速度変更、シーク、全画面表示に対応します。燃焼の時間は鑑賞用に短縮しています。

## 素材と描画

`burn-stages.webp` は、内蔵の画像生成で制作した4コマの写真的な素材です。左上が着火、右上が熾火、左下が灰に覆われた薪、右下が崩落後の灰です。`flame-stages.webp` には同じ方法で生成した透過付きの炎を収録しています。ブラウザが同じ構図で各段階をつなぎ、炎・煙・火の粉や落ちる灰を動かします。外部の画像や動画は読み込みません。
