壁紙を追加する

GitHub から自作の壁紙を投稿できます。Pull Request がマージされると、この一覧に掲載されます。

  1. リポジトリをフォークする

    自分の GitHub アカウントにコピーを作り、作業用のブランチを作成します。

    GitHub でフォークする ↗

  2. 壁紙と掲載情報を追加する

    docs/wallpapers/ に壁紙を置き、名前と説明を一覧のデータに登録します。

    詳しい追加手順を見る ↗

  3. Pull Request を送る

    自分のブランチに変更をプッシュし、このリポジトリの main に追加を提案します。

    GitHub で変更を比較する ↗
